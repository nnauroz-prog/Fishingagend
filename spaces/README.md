# Fishingagend auf Hugging Face Spaces

Multi-Agenten-KI-Vorhersage-Engine. Ohne `ANTHROPIC_API_KEY` läuft die App
mit deterministischem Mock-LLM — alles klickbar, aber Agenten-Antworten
sind Platzhalter. Mit Key (Settings → Repository secrets) reden die
Agenten echt.
